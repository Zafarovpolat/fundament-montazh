# ФундаментМонтаж

Адаптивная HTML/CSS/JS-страница на основе фрейма **«Главная» / 315:160** из предоставленного Figma-макета.

## Запуск

```sh
python3 -m http.server 5173 --bind 0.0.0.0
```

Откройте `http://localhost:5173`. Можно также открыть `index.html` напрямую. Сайт не использует runtime-библиотеки, CDN и внешние API.

## Адаптивная архитектура

Предыдущая координатная версия заменена обычной вёрсткой:

- Центрированный `.container`: `max-width: 1660px`, автоматические внешние отступы, изменяемые боковые поля.
- Фон секций занимает ширину окна независимо от максимальной ширины контента.
- Секции, текст и карточки находятся в обычном потоке. Grid/Flex перестраивают колонки на планшете и телефоне.
- Нет `zoom`, масштабирования страницы через `transform`, холста 1920 px, фиксированной общей высоты или координатного позиционирования текста.
- Абсолютное позиционирование используется только для фоновых изображений, меток на фотографиях и подписи поверх фотографии объекта.
- Нет глобального скрытия горизонтального переполнения. Горизонтальная прокрутка ограничена каруселями проектов и отзывов, доступными через стрелки, клавиатуру и сенсорные жесты.
- FAQ использует нативные `details`/`summary`: раскрытие увеличивает высоту секции и сдвигает следующий контент.
- На узких экранах — раскрываемая навигация, перестройка колонок, переносы текста и кнопок.
- Пустой участок после геологии, связанный с фиксированной геометрией исходника, удалён.

Мобильный макет не предоставлялся: адаптация выполнена самостоятельно по согласованию с владельцем. Сохраняются визуальный стиль, изображения и основное содержание desktop-макета, но это не фиксированная попиксельная копия фрейма при любой ширине окна.

## Файлы

- `index.html` — семантическая структура, header, main, section, article, figure, footer, диалог и форма.
- `styles.css` — переменные, центрированный контейнер, компоненты, Grid/Flex, медиазапросы.
- `fonts.css` — локальные `@font-face`.
- `app.js` — меню, диалог, демонстрационная форма, фильтры, квиз и управление каруселями. Размеры страницы JavaScript не меняет.
- `assets/` — локальные изображения из Figma и шрифты.
- `tests/smoke.cjs` — адаптивные и функциональные браузерные проверки.

Устаревший `layout.css` удалён: правила фиксированного холста больше не используются.

## Шрифты

Подключены все 18 предоставленных начертаний, преобразованные в WOFF2 с полным набором символов:

- **CoFo Sans:** 400, 500, 700, 900 — обычные и курсивные.
- **Euclid Circular A:** 300, 400, 500, 600, 700 — обычные и курсивные.

Веса и стили прочитаны из метаданных. Regular обоих семейств предзагружается; остальные браузер загружает по необходимости. Исходники сохранены в `assets/fonts/cofo-sans/` и `assets/fonts/euclid-circular-a/`, веб-версии — в `assets/fonts/web/`.

**Ouvality** для подписи руководителя не предоставлен; для него остаётся резервный шрифт. Искусственного сжатия текста нет.

## Интерактивные элементы

- Якорная навигация и телефонные ссылки.
- Мобильное меню с `aria-expanded`, закрытием после перехода и по Escape.
- Диалог с закрытием кнопкой, по фону и по Escape.
- Валидация имени/телефона, подготовка скачиваемой текстовой заявки.
- Фильтры с пустым состоянием: все четыре карточки в исходном макете имеют одинаковые характеристики.
- Прокрутка проектов и отзывов на фактическую ширину карточки, а не на фиксированное число пикселей.
- Нативный FAQ.
- Демонстрационный квиз из четырёх вопросов. В макете был только первый экран; остальные вопросы добавлены для демонстрации поведения. Выдуманная цена не рассчитывается.

## Проверки

```sh
npm test
npm install
npx playwright install --with-deps chromium
# В другом терминале должен быть запущен HTTP-сервер:
npm run test:browser
```

Проверяются:

- Ширины 320, 375, 390, 480, 640, 768, 960, 1024, 1100, 1280, 1440, 1920, 2560 и 3840 px.
- Отсутствие горизонтального переполнения страницы без его маскировки.
- Центрирование и ограничение ширины контейнера.
- 18 загруженных начертаний, один h1, отсутствие фиксированного холста.
- Только верхняя граница нижней строки футера.
- Мобильное меню, форма, фильтры, карусель, квиз.
- Раскрытие FAQ в потоке и переносы длинного заголовка.
- Отсутствие ошибок JavaScript и HTTP в проверенных сценариях.

Ширины 960/640 px также проверяют размер layout viewport, эквивалентный окну 1920 px при масштабе 200/300%. Это проверка перестроения при соответствующей ширине, не отдельная автоматизация браузерных кнопок изменения масштаба.

## До рабочего запуска

1. Подключить backend: сейчас данные формы не отправляются, интерфейс сообщает об этом явно.
2. Предоставить ссылки на соцсети, видео, полный каталог и юридические документы. Вместо выдуманных адресов используются информационные диалоги.
3. Утвердить тексты FAQ, цены, телефон, ипотечные условия и противоречия исходных текстов. В исходнике блока «6 шагов» заполнен только первый шаг — остальные не выдуманы.
4. При необходимости предоставить Ouvality и согласовать финальные визуальные нюансы адаптивной версии.

Изображения, логотип, тексты и коммерческие шрифты принадлежат соответствующим правообладателям. Публичный репозиторий не означает открытой лицензии на эти материалы. Опубликованные в переписке ключи следует отозвать; ключи в исходники не включаются.
