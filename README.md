# ФундаментМонтаж

Статическая desktop-версия фрейма **«Главная» / 315:160**, Figma-файл `OI1QsiS9LrdOCIIflblvMs`.

HTML, CSS и JavaScript без runtime-библиотек, CDN и внешних сетевых запросов. Изображения экспортированы из предоставленного макета и оптимизированы в WebP. Текст остаётся HTML-текстом: страница не является скриншотом.

## Запуск

```sh
python3 -m http.server 5173 --bind 0.0.0.0
```

Откройте `http://localhost:5173`. Также можно открыть `index.html` непосредственно в браузере.

## Структура

- `index.html` — секции страницы, заголовки, навигация, карточки, кнопки, диалог и форма.
- `styles.css` — переменные, общие компоненты, состояния, доступность, масштабирование.
- `layout.css` — геометрия и типографические параметры исходного фрейма. Суффиксы классов соответствуют идентификаторам Figma; `data-node` помогает находить исходные элементы.
- `app.js` — интерактивные элементы без зависимостей.
- `assets/` — локальные изображения из Figma.
- `tests/smoke.cjs` — браузерные smoke-тесты.

Секции находятся в обычном вертикальном потоке. Внутри секций применяется координатное позиционирование по Figma. Это **фиксированная desktop-композиция**, а не завершённая fluid/grid-вёрстка для произвольного текста.

## Что работает

- Якорная навигация и телефонные ссылки.
- Диалог с закрытием по Escape, по фону и кнопкой, возвратом фокуса.
- Проверка обязательных полей и подготовка скачиваемой текстовой заявки.
- Фильтры каталога, включая честное пустое состояние. Все четыре карточки в исходнике имеют одинаковые характеристики.
- Переключение карточек проектов, отзывов и преимуществ.
- Раскрытие FAQ. Тексты ответов подготовлены на основе сведений макета и требуют утверждения владельцем.
- Квиз из четырёх вопросов. В макете есть только первый экран: последующие три реализованы как демонстрационный сценарий, без вычисления фиктивной цены.

## Важно: точность и ограничения

**Эта версия не заявляется как окончательный pixel-perfect 1:1.**

1. Размер исходника — **1920 × 15963 px**. Большой пустой участок после геологии, повторные карточки, несогласованности текста и незаполненный блок этапов сохранены из макета. Это не ошибка загрузки.
2. Оригинальные файлы **CoFo Sans**, **Euclid Circular A**, **Ouvality** не предоставлены. CSS использует эти имена, если шрифты установлены локально, иначе резервные системные шрифты. Метрики, переносы и подпись руководителя могут отличаться. Для окончательного совпадения нужны лицензированные WOFF2 и дополнительная визуальная проверка.
3. Мобильного фрейма не было: desktop-композиция пропорционально масштабируется. Это **не отдельный адаптивный мобильный интерфейс**, мелкий текст на телефоне — известное ограничение. Диалог формы адаптирован отдельно.
4. Сервер обработки заявок не подключён. Форма не отправляет персональные данные и явно сообщает об этом пользователю. Подготовленную заявку можно скачать.
5. Точные ссылки соцсетей, видео, отдельных проектов и юридические документы не предоставлены. Такие действия не перенаправляют на выдуманные адреса; используются информационные диалоги или пояснения. Телефон, цены и маркетинговые условия перенесены из макета, их актуальность не проверялась.
6. Графика, логотип и тексты принадлежат соответствующим правообладателям. Публичность репозитория не означает открытой лицензии на эти материалы. Коммерческие шрифты намеренно не скачивались из сторонних источников.

## Подключение оригинальных шрифтов

Поместите лицензированные файлы в `assets/fonts/`, добавьте в начало `styles.css`:

```css
@font-face {
  font-family: 'CoFo Sans';
  src: url('assets/fonts/cofo-sans-regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
@font-face {
  font-family: 'Euclid Circular A';
  src: url('assets/fonts/euclid-circular-a-regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
@font-face {
  font-family: 'Ouvality';
  src: url('assets/fonts/ouvality.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
```

Для отдельных элементов также нужен CoFo Sans Medium, вес 500.

## Проверки

```sh
npm test
# Браузерные тесты; HTTP-сервер должен быть запущен:
npm install
npx playwright install --with-deps chromium
npm run test:browser
```

Проверено в Chromium: один h1, высота страницы 15963 px при ширине 1920 px, диалог, валидация формы, фильтры, FAQ, квиз, карусель, отсутствие горизонтального скролла на 390 px и ошибок JavaScript/HTTP в проверенных сценариях. Отсутствие горизонтального скролла не означает завершённую мобильную адаптацию.

## Перед рабочим запуском

- Подключить оригинальные шрифты и выполнить попиксельное сравнение.
- Согласовать пустые участки и повторяющиеся/противоречивые тексты.
- Сделать мобильную и планшетную вёрстку по отдельным требованиям.
- Подключить backend, политику обработки данных и необходимые согласия.
- Добавить реальные URL, документы и подтвердить цены/контакты.
- Отозвать опубликованные в переписке ключи Figma и GitHub. В репозиторий ключи не включены.
