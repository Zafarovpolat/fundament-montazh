# Фрагменты секций для других страниц

Здесь лежат самодостаточные куски вёрстки, которые переиспользуются на
второй и последующих страницах. Каждый набор — разметка секции плюс её
стили, собранные инструментом; ручное редактирование не нужно.

| Файл | Что это |
|---|---|
| `projects.html` | Секция «Готовые проекты» (макет `315:160`, `#projects`) — разметка без изменений, как на главной |
| `projects.css` | Все правила, которые реально действуют на узлы этой секции (включая глобальные `:root`/`html`/`body` и базовую типографику) |

## Подключение на новой странице

```html
<link href="fonts.css" rel="stylesheet" />
<link href="styles.css" rel="stylesheet" />
<link href="figma-type.css" rel="stylesheet" />
<link href="fidelity.css" rel="stylesheet" />
<link href="compact.css" rel="stylesheet" />
<link href="compact-type.css" rel="stylesheet" />
<link href="interactions.css" rel="stylesheet" />
<link href="sections/projects.css" rel="stylesheet" />
```

Затем в `<main>` — содержимое `projects.html`. Обязательны общие скрипты
(`motion.js`, `sliders.js`, `layout.js`, `refinements.js`, `app.js`): карточки
и кнопки в этой секции досчитываются JS, без них ширина карточки и высота
кнопки отличаются (замерено: `.button-icon` 60x73 с JS против 60x63 без).

Проверка: копия секции, добавленная в ту же страницу (`cloneNode`), даёт
пиксель-в-пиксель те же размеры, что и оригинал — 5 из 5 `.button-icon`
совпали, `inline-стилей` на них нет. Значит фрагмент + базовые стили
самодостаточны.

`projects.css` — самодостаточная КОПИЯ всех правил, действующих на секцию
(для переноса в Bitrix-компонент или в страницу без общих стилей). На
странице, где уже подключены базовые файлы, её подключать НЕ нужно:
продублированные правила оказываются в конце цепочки и переопределяют более
поздные переопределения из `fidelity.css`/`compact.css`. Это не теория —
на тестовой странице так и произошло: у `.heading-description` цвет
стал `rgb(0,0,0)` вместо `rgba(7,11,31,.65)`, и `test:fidelity` это поймал.

## Как пересоздать после правок вёрстки

```sh
python3 tools/extract_section_css.py --section projects --apply   # режим bundle (по умолчанию)
```

Инструмент ничего не меняет в основных стилях — только перезаписывает файл
бандла. Перед удалением секции с главной (для этого есть `--mode move`)
обязательно сверять порядок каскада: `npm run test` и `npm run test:fidelity`.
